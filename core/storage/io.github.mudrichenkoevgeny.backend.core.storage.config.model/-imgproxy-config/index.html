ImgproxyConfig

data class ImgproxyConfig(val isEnabled: Boolean, val baseUrl: String, val key: String, val salt: String, val presets: Map<String, ImgproxyPreset> = emptyMap(), val videoThumbnailSecond: Int)

Configuration parameters for the imgproxy media preview and thumbnail generation service.

Holds connection settings, HMAC signing keys, preset specifications, and default video frame extraction settings.

Parameters

isEnabled

whether imgproxy preview and thumbnail generation is enabled.

baseUrl

base URL of the imgproxy service.

key

hex-encoded secret key used for HMAC-SHA256 URL signing.

salt

hex-encoded salt used for HMAC-SHA256 URL signing.

presets

map of preset keys (such as "thumbnail" or "avatar_sm") to ImgproxyPreset specifications.

videoThumbnailSecond

default seek time in seconds when extracting thumbnail frames from video files.
