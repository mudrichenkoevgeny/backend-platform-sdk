StorageError

sealed class StorageError : AppError

Storage feature errors: file upload limits, quotas, media validation, and S3 operations.

Uses publicArgs for client-visible data; secretArgs for internal logs only. Each variant has a stable code for i18n and a unique errorId for correlation.
