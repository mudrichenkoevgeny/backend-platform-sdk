S3StorageService

@Singleton
class S3StorageService @Inject constructor(config: StorageConfig, imgproxyUrlBuilder: ImgproxyUrlBuilder, appLogger: AppLogger) : StorageService

S3-backed implementation of StorageService using AWS SDK v2 async client and presigner.

Configured using StorageConfig for endpoint, region, access credentials, bucket name, and public URL. Upload, delete, and head object operations execute asynchronously via S3AsyncClient and S3Presigner.

Parameters

config

Configuration parameters holding S3 credentials, endpoint, and bucket options.

imgproxyUrlBuilder

Service used to construct signed imgproxy thumbnail and preview URLs.

appLogger

Application logger instance used for recording infrastructure errors.
