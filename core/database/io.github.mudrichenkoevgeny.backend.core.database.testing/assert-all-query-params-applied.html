assertAllQueryParamsApplied

suspend fun <QueryParams : Any> assertAllQueryParamsApplied(queryParamsClass: KClass<QueryParams>, defaultInstance: QueryParams, ignoredProperties: Set<String> = emptySet(), executeRepoCall: suspend (QueryParams) -> Unit)

Asserts that every property in queryParamsClass (excluding ignoredProperties) alters the generated SQL query (WHERE, ORDER BY, or JOIN clauses) when passed to executeRepoCall.

Runs inside an Exposed transaction, intercepts SQL queries via CapturingSqlLogger, and compares the mutated property SQL against the baseline SQL.

Parameters

KClass of the QueryParams data class (e.g. UserListQueryParams::class)

defaultInstance

instance of QueryParams with default/empty filter values

ignoredProperties

suspend lambda executing the repository query method with given QueryParams
