RedisManagerImpl

@Singleton
class RedisManagerImpl @Inject constructor(redisClient: RedisClient, scope: CoroutineScope) : RedisManager

Default RedisManager implementation backed by a Lettuce RedisClient.

Lazily obtains a single StatefulRedisConnection (thread-safe via mutex), runs commands asynchronously with await, and wraps failures in AppResult.Error or AppSystemResult.Error with CommonError.Internal. shutdown closes the connection and the client.
