@Singleton
class PasswordHasherImpl @Inject constructor(appLogger: AppLogger) : PasswordHasher

Default PasswordHasher implementation based on Password4j.

Uses Argon2 with a random salt for hashing and verification. Any unexpected exception is logged via AppLogger and then rethrown (this keeps failures visible to the caller and preserves stack traces).
