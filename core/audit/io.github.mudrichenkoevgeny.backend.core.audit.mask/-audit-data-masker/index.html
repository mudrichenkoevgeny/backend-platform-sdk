AuditDataMasker

object AuditDataMasker

Redacts sensitive fields on AuditEventInternal for display or API responses, converting them into AuditEventPrivate.

Uses the shared foundation model's sensitivity hints:

  • AuditEventPrivate.resourceId is masked according to AuditEventInternal.resourceValueSensitivity.

  • Each metadata entry's value is masked using that entry's AuditEventMetadata.key sensitivity (same AuditValueSensitivity enum as for AuditEventInternal.resourceValueSensitivity).

Masking delegates to DataMasker (email, phone, IP, partial/full). Converts internal domain audit events (AuditEventInternal) into sanitized private models (AuditEventPrivate) when callers require masked views.
