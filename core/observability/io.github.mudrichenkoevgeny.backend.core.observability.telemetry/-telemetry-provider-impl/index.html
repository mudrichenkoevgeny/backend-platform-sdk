TelemetryProviderImpl

@Singleton
class TelemetryProviderImpl @Inject constructor(observabilityConfig: ObservabilityConfig) : TelemetryProvider

Default TelemetryProvider implementation.

Uses GlobalOpenTelemetry.get for OpenTelemetry, tracer and meter with ObservabilityConfig.telemetryServiceName. Builds a PrometheusMeterRegistry and binds JVM metrics (memory, GC, threads, processor, classloader) to it. warmup starts and ends a short span to ensure the tracer is ready.
