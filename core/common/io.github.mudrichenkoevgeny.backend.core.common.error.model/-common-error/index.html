CommonError

sealed class CommonError : AppError

Common application errors for request handling, validation, and infrastructure.

Distinguishes publicArgs (exposed to the client and used in localized messages) from secretArgs (for logs only). Each variant has a stable code for i18n and a unique errorId for correlation.
