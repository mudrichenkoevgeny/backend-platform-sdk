Default WebSocketManager implementation backed by Ktor's WebSocket server APIs.

Manages registration, routing of incoming frames to WebSocketMessageHandlers, lifecycle notifications for WebSocketSessionListeners and error logging.

Employs Redis Pub/Sub to enable a stateless architecture. Notifications sent via sendMessageToAll, sendMessageToUser, etc., are broadcast over Redis so that any instance hosting the target socket can deliver the frame.
