abstract suspend fun createSession(userId: UserId, userRole: UserRole, identifier: String, identifierId: UserIdentifierId, identifierDisplayName: String = identifier, identifierAuthProvider: UserAuthProvider, clientInfo: ClientInfo, lastReauthenticatedAt: Instant, checkNewDevice: Boolean = true): AppResult<SessionToken>

Creates a new session for the given user and identifier.

Return

AppResult.Success with SessionToken or an error.

Parameters

userId

The unique identifier of the user.

userRole

The role of the user to be encoded in the session data.

identifier

The literal identifier value (e.g., email or phone) used for this session.

identifierId

The ID of the specific identifier used to authenticate.

identifierDisplayName

The display name of the identifier.

identifierAuthProvider

The authentication provider used to authenticate.

clientInfo

Client metadata (device, IP, etc.) to bind to the created session.

lastReauthenticatedAt

Timestamp used to track re-authentication requirements.

checkNewDevice

Whether to check for new device login.
