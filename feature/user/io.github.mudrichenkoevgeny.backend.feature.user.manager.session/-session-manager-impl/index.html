Default SessionManager implementation.

Generates access tokens via TokenProvider and refresh tokens via RefreshTokenProvider, persists session records through UserSessionRepository, and performs refresh/revocation operations inside dbQuery.

Uses UserConfig token validity settings to compute token expiration timestamps.
