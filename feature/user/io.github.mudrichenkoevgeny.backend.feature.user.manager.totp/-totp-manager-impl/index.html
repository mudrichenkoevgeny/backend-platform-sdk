@Singleton
class TotpManagerImpl @Inject constructor(userTotpSettingsRepository: UserTotpSettingsRepository, userRepository: UserRepository, aesCryptor: AesCryptor, totpCryptoProcessor: TotpCryptoProcessor) : TotpManager

Default TotpManager implementation coordinating TOTP lifecycle and security.

Utilizes TotpCryptoProcessor for time-based code verification and AesCryptor for securing recovery codes. Orchestrates state changes between UserTotpSettingsRepository and UserRepository within dbQuery blocks to ensure atomic activation and deactivation.
