open suspend override fun recordFailedAttempt(identifier: String, type: LockoutAttemptType, userId: UserId? = null): AppResult<Unit>

Records a failed authentication attempt for a single identifier.

Return

AppResult.Success if no lockout was triggered, or AppResult.Error with UserError.UserLocked if lockout triggered.

Parameters

identifier

Unique key string used for tracking failed attempts (e.g., login email, phone number, or user ID UUID string).

type

Type of failed attempt (LockoutAttemptType.PASSWORD, LockoutAttemptType.OTP, LockoutAttemptType.TOTP).

userId

Optional user ID to persist lockout state in storage if a lockout is triggered.
