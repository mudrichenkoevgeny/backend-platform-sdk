WebSocketPubSubMessage

@Serializable
data class WebSocketPubSubMessage(val targetType: WebSocketPubSubMessage.TargetType, val targetId: String?, val apiScope: ApiScope?, val frame: SocketFrame)

Message payload published to Redis Pub/Sub for broadcasting WebSocket events across the cluster.

Each Ktor instance listens for these messages and dispatches the embedded frame to the appropriate locally-connected clients based on targetType and target identifiers.

Parameters

targetType

Defines the audience of the message (all users, specific user, single socket, etc.).

targetId

The identifier for the target. Null when targetType is TargetType.ALL or TargetType.SCOPE.

apiScope

The required API scope of the target clients. Null if the message is not scoped.

frame

The actual payload frame that will be serialized to JSON and sent to the WebSocket clients.
