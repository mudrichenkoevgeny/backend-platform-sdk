UserError

sealed class UserError : AppError

User and authentication feature errors: tokens, sessions, credentials, and account state.

Uses publicArgs for client-visible data; secretArgs (e.g. UserId) for logs only. Each variant has a stable code for i18n and a unique errorId for correlation.
