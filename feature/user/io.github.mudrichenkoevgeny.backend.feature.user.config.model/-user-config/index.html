UserConfig

data class UserConfig(val jwtSecret: String, val adminAccountsList: List<AdminAccount>, val managementAuthSettings: ManagementAuthSettings, val googleWebClientId: String?, val uniOneConfig: UniOneConfig?, val resendConfig: ResendConfig?)

Configuration for the user feature.

This config is intended to be created at application startup (typically via a config factory) and injected into feature components that need auth, seeding, and external provider settings.

Parameters

jwtSecret

secret used to sign and verify JWT tokens

adminAccountsList

initial admin accounts to seed on startup

managementAuthSettings

default auth settings: available providers and access/refresh token lifetimes

googleWebClientId

optional Google web client id used to verify Google tokens

uniOneConfig

optional UniOne email provider config (null when not configured)

resendConfig

optional Resend email provider config (null when not configured)
