authenticateOrCreateUser

open suspend override fun authenticateOrCreateUser(clientInfo: ClientInfo, userAuthProvider: UserAuthProvider, identifier: String, password: String? = null, externalProviderEmail: String? = null, externalProviderDisplayName: String? = null, roleForUserCreation: UserRole = UserRole.USER, accountStatusForUserCreation: UserAccountStatus = UserAccountStatus.ACTIVE, authorityLevelForUserCreation: Int = 0, permissionCodesForUserCreation: Set<PermissionCode> = setOf(), allowedRoles: Set<UserRole> = UserRole.entries.toSet(), allowedAccountStatuses: Set<UserAccountStatus> = setOf( UserAccountStatus.ACTIVE, UserAccountStatus.READ_ONLY )): AppResult<AuthData>

Authenticates a user or creates a new one if they don't exist.

  • If the identifier is not found, a new user and corresponding identifier are created using the provided default roles and permissions. If the user exists, it performs standard authentication.

Return

AppResult with AuthData containing user details and the session token.

Parameters

clientInfo

Information about the client device and environment.

userAuthProvider

The authentication method used (e.g., EMAIL, GOOGLE).

identifier

The unique string for the provider (email, phone number, or social ID).

password

The raw password (required for EMAIL provider).

externalProviderEmail

Optional email from an external provider to link accounts if an email identifier already exists.

externalProviderDisplayName

Optional display name from an external provider.

roleForUserCreation

Role assigned if a new user is created. Defaults to UserRole.USER.

accountStatusForUserCreation

Initial status if a new user is created. Defaults to UserAccountStatus.ACTIVE.

authorityLevelForUserCreation

Explicit authorityLevel for the new user. Defaults to 0

permissionCodesForUserCreation

Set of initial permissions if a new user is created.

allowedRoles

Allowed roles for the authenticated user.

allowedAccountStatuses

Allowed account statuses for the authenticated user.
