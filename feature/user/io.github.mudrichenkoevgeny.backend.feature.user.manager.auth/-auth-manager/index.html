AuthManager

interface AuthManager

Orchestrates authentication operations for the user feature.

Coordinates user loading, identifier creation, and session creation to produce AuthData for clients. This manager serves as the high-level entry point for all authentication flows, including registration, login, and multifactor authentication completion.
