RotatedRefreshTokenData

@Serializable
data class RotatedRefreshTokenData(val sessionId: String, val identifierId: String, val accessToken: String, val refreshToken: String, val expiresAt: Instant, val userId: String, val rotatedAt: Instant)

Represents cached metadata for a previously rotated refresh token.

Used during refresh token rotation with a grace period to support client retries and detect replay attacks. If an old refresh token is presented within the grace window, the corresponding new SessionToken is returned without generating a fresh session. If presented outside the grace window, security measures (such as account security hold) are triggered.
